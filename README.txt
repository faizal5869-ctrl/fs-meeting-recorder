FS MEETING RECORDER — PANDUAN RINGKAS

KANDUNGAN
- index.html, app.js, manifest.json, sw.js: fail aplikasi web ringkas.
- Aplikasi menyimpan nota dan tugasan dalam localStorage pelayar.
- Tiada akaun, pelayan, cloud atau API berbayar.
- Ini prototaip; ia belum mempunyai transkripsi automatik atau ringkasan AI.

PENTING
Rakaman mikrofon biasanya memerlukan laman HTTPS (atau localhost). Jika index.html dibuka terus dari folder, borang nota boleh digunakan tetapi rakaman mungkin tidak tersedia. Untuk memasang di telefon Android sebagai aplikasi web, muat naik fail ini ke hos statik HTTPS percuma seperti GitHub Pages, kemudian buka pautan itu dalam Chrome Android > menu tiga titik > Add to Home screen / Install app.

CARA MUAT TURUN ZIP
1. Muat turun fail ZIP.
2. Di Windows, buka File Explorer > Downloads.
3. Klik kanan ZIP > Extract All > Extract.
4. Jangan padam folder yang diekstrak; itulah fail aplikasi.

DATA
Data nota disimpan pada pelayar/peranti yang digunakan. Ia tidak disegerakkan automatik antara laptop dan telefon. Gunakan butang Eksport semua data untuk membuat sandaran JSON secara berkala.
